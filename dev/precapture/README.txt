Offline pre-capture protocol prototype

This is an implementation experiment, not a camera feature or installer.
offline_codec.c implements setting/shooting message encoding. It contains no
USB access, firmware hooks, hard-coded target state address, or constructor.
The ELF files generated by verify_offline.py are local emulator test inputs.
Do not rename them libJit.so or send them to a camera.

Reproduce with private original research inputs (never distribute firmware):

python -m pip install unicorn capstone pyelftools
python dev/precapture/verify_offline.py --firmware-root PRIVATE_FIRMWARE_FOLDER --zig PATH_TO_ZIG --output NEW_PRIVATE_OUTPUT

The firmware folder must contain the original a1ii-4.00/components/appFw.so
and cpapp-b.bin with the pinned fingerprints. Zig 0.13 was used.
No complete firmware or generated artifacts belong in this source directory.

262 checks passed: native AArch64 and Thumb encoders, 20 durations, 3 triggers,
2 modeled domain values, 4 shooting combinations and 7 invalid-input cases
per architecture. Valid payloads match execution of the actual original
donor conversion instructions. Their domain dependency is explicitly
modeled as 0/1, not established as a usable A7C II runtime field.

Still missing: target AP sender/placement, CP state ownership and async
scheduler binding, image buffer allocation/lifetime, S1/S2 synchronization,
frame retention, save/cancel handling and physical acceptance. Do not infer
that this code implements pre-shutter photography from codec test success.
