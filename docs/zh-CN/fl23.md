# FL2／FL3：安装与核对

[返回首页](../../README.zh-CN.md) · [English](../en/fl23.md)

在 **Windows** 解压最新工具包，打开 **FL23.cmd**。它只为精确支持的原厂 **A7C II 固件 2.01** 安装 FL2／FL3，不要在已修改的六款机身上运行。Mac 可执行[离线文件检查](manual.md#macos)，macOS 设备安装尚未验证。

## 准备

1. 安装带 Windows `py` 启动器和 Tkinter 的 64 位 Python 3.10+。首次启动需联网安装依赖，不需要升级 PowerShell。
2. 相机设为 **USB 大量存储／Mass Storage**，使用数据线。通过 [Zadig](https://zadig.akeo.ie/) 仅为相机安装 **libusbK**：普通身份 `054C:0E8A`、服务身份 `054C:0336`。后者首次认证后才出现，不要修改其他设备驱动。
3. 选择两个新的空白工作／备份目录，尽量放在不同磁盘；保留旧目录。

## 安装与核对

1. 先运行 **「1 備份與檢查」**，检查来源并保存本机备份。这一步运行临时诊断，不重写程序文件或保存拍摄设置。
2. 准备成功后，填写实际电量（至少 50%），选择 **「2 安裝預覽版」**。保持供电和 USB，直到读回、核对与清理全部完成。
3. 工具结束后拔除 USB 和其他供电，正常关机，等待存取灯熄灭，取出电池至少一分钟后再开机。
4. 检查新 FL2／FL3 和原有 ST 拍照／回放，再接回执行 **「3 重開後核對」**。

## 出错时

服务身份驱动缺失时，为 `054C:0336` 安装驱动，保留失败目录，确认状态后才在新目录重新准备。最新工具已整合初始就绪／忙碌的有界等待。超时、断线或写入结果未知时，应检查已有结果，不要再次点击安装。还原只接受本机已核对的备份及受支持来源。

机主单台机身的基础 FL2／FL3 测试已通过。项目仍属实验研究，没有 Sony 签名存储卡更新包、通用恢复保证或第二台机身的稳定性验证。
