# AI 接手

[返回首页](../../README.zh-CN.md) · [English](../en/ai.md)

使用同一个 `main`，通过目录和命令选择功能，不需要切换分支。下面这段可直接交给编码助手：

> 先读 AGENTS.md 和 docs/zh-CN/ai.md。确认我要 FL2／FL3 还是 DCP／LUT 自定外观。
> 使用现有工具、精确来源检查及已测试的还原清单，不要猜偏移或移植其他机身的设置。
> 先跑离线检查，保存包含来源哈希、目标栏位、备份、当前阶段、命令退出码、产物及错误的私人工作记录。
> 保留未选配方及 FL／FL2／FL3；不要重跑结果未知的 USB 写入。
> 不要把候选、清单、名称、模拟或磁盘读回当成实机完成，明确回报还缺什么。

## 操作顺序

1. `FL23.cmd --check` 检查 Python；`FL23.cmd --setup-only` 或 `Custom-LUT.cmd --setup-only` 准备环境，均不连接相机。
2. FL2／FL3 使用 `src/fl23/` 的 `prepare → install → verify`，每一步核对成功后才继续；手动命令见 [手动命令](manual.md)。
3. DCP／LUT 使用 `src/looks/` 的 `inspect → plan → check-bindings → calibrate → fit → prepare-transition`。需要量测校准、精确来源和真实保存／运行绑定，不能伪造默认值。
4. 仅有精确历史三款来源时，`prepare-six-program` 可重建六款程序候选；它不负责 68 份名称资源、现场 ST 设置、设备写入及启动状态处理。
5. 来源不匹配、缺少校准／资源或结果未知时，保存诊断并在写入前停止，不要放宽检查来“成功”。

写入前必须有本机新鲜原档／设置、两份独立核对备份、精确前置条件、原生只校验与测试过的还原路径。写后需要完整读回、保存设置核对、只读挂载／清理、实际加载状态，以及不按快门的预览和新照片测试。

完整技术说明见[实现与设备集成](technical/integration.md)；之前的循环重启、空白名称、分支指令中间入口和预览卡色错误见[历史错误](technical/failures.md)。

这些入口用于减少重复研究和操作差异，**不能保证任何 AI 对任意相机一次安装成功**。公开工具尚无一条命令完成原厂到六款升级；不应把机主私人流程的成功当作通用安装器已经完成。
