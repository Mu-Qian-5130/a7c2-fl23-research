# FL2 / FL3 — installation

[Home](../../README.md) · [简体中文](../zh-CN/fl23.md)

Open **FL23.cmd** in the latest tools ZIP. It installs FL2/FL3 only on the exact supported original **A7C II firmware 2.01** source. Do not run it over a modified six-look build.

## Prepare

1. Install 64-bit Python 3.10+ with the Windows `py` launcher and Tkinter. First launch needs Internet access for dependencies. No PowerShell upgrade is required.
2. Set the camera to **USB Mass Storage** and use a data cable. With [Zadig](https://zadig.akeo.ie/), install **libusbK** only for the camera identities: normal `054C:0E8A`, service `054C:0336`. The service identity appears after initial authentication; do not change other devices' drivers.
3. Choose two new empty work/backup folders, preferably on separate drives. Keep previous folders.

## Install and verify

1. Run **「1 備份與檢查」** first. This checks source eligibility and saves this body's backups. Temporary diagnostics run, but program files and saved shooting settings are not rewritten.
2. After preparation succeeds, enter the actual battery percentage (at least 50%) and select **「2 安裝預覽版」**. Keep USB and continuous power until all readback and cleanup finish.
3. Once the tool finishes, disconnect USB and other power, shut down normally and wait for the access lamp to go out. Remove the battery for at least one minute, reinstall and boot.
4. Test new FL2/FL3 and existing ST photos/playback. Reconnect and run **「3 重開後核對」**.

## If it stops

If the service driver is missing, install the driver for `054C:0336`, keep the failed workspace and clarify the state before preparing again in fresh folders. The latest tool already includes bounded initial readiness/busy handling. A timeout, disconnect or unknown write result requires inspecting the existing result; do not press Install again. Restore requires this body's own verified backup and supported source.

The owner's basic FL2/FL3 tests passed on one body. This is experimental research, without a Sony-signed memory-card updater, guaranteed recovery or second-body stability validation.
