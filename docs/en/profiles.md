# DCP reference downloads

[Home](../../README.md) · [简体中文](../zh-CN/profiles.md)

The Release attachment contains all **18 original, unchanged DCP files** supplied by the repository owner:

- **MTriton Fuji-style (11):** Provia, Velvia, Astia, Classic Chrome, Pro Neg Std, Pro Neg Hi, Eterna, Reala Ace, Classic Negative, Nostalgic Negative, Bleach Bypass.
- **Sony-adapted Ricoh GR III (7):** Standard, Vivid, Positive Film, Negative Film, Monotone, Hard Monotone, Soft Monotone.

**DCP sources on Xiaohongshu (小红书):**

- **Ricoh DCPs:** **爸总林先森**.
- **Fujifilm DCPs:** **门萨特里顿** (MTriton).

These are RAW-development profiles for **Sony ILCE-7CM2**, not camera firmware. On Windows, copy DCPs into `%APPDATA%\Adobe\CameraRaw\CameraProfiles`, restart Lightroom/Camera Raw and select an A7C II RAW. In-camera conversion uses the separate research toolkit; downloading DCPs does not install them into the camera.
